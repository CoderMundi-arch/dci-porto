# DCI Dental Care Institute — Website

## Estrutura
- `index.html` — Home
- `quem-somos.html` — Institucional / Quem Somos
- `blog.html` — Listagem de artigos, filtros e pesquisa
- `contacto.html` — Formulário, horários, contactos e mapa
- `infraestrutura.html` — Galeria da clínica, consultórios, receção, formação e equipa
- `css/styles.css` — Estilos partilhados e responsivos
- `js/main.js` — Menu mobile, filtros, pesquisa e feedback dos formulários
- `assets/` — Fotografias utilizadas no layout, incluindo imagens da infraestrutura extraídas da referência enviada

## Como executar
1. Extraia o ZIP.
2. Abra `index.html` no navegador ou execute um servidor local.
3. Os links do menu ligam as quatro páginas.

## Antes de publicar
- Ligar o formulário de contacto a um backend, SMTP, CRM ou serviço de formulários.
- Ligar a newsletter a uma plataforma de e-mail.
- Substituir os links provisórios dos artigos por URLs reais.
- Rever os textos, horários, contactos e fotografias com a DCI.
- Adicionar páginas individuais de artigo, política de privacidade e consentimento de cookies, se aplicável.

O projeto é HTML/CSS/JS estático. Os formulários têm validação no navegador, mas não enviam dados para um servidor.

## Página Infraestrutura
A galeria possui controlos anterior/seguinte e indicadores, adaptando a quantidade de imagens visíveis ao ecrã. A secção de equipa apresenta as áreas e o modelo de acompanhamento sem inventar nomes ou fotografias de profissionais. Substitua/complete essa secção com retratos e mini-biografias aprovados pela clínica quando esses materiais estiverem disponíveis.
